# Notas do Projeto Original (fotos do usuário)

## Menu Lateral
- Shopee Zap (logo raio roxo/rosa)
- Dashboard
- Meus Links
- Agendamentos
- Histórico
- Chatbot
- Notificações (badge com número)
- Configurações

## Dashboard
- Título: "Dashboard" / "Visão geral da sua automação de links da Shopee"
- Cards: Links Cadastrados, Agendamentos, Enviados, Falhas, Pendentes
- Seção "Próximos Envios" com lista (nome + dia/hora)
- Link "Ver todos →"
- Filtro "Semanal"

## Meus Links
- Título: "Meus Links" / "Gerencie seus links de afiliados da Shopee"
- Card horizontal: imagem à esquerda, título, descrição, preço (R$ 24,88), desconto (45% OFF), tag categoria (cozinha), link "Ver na Shopee", botões editar/excluir
- Botão "+ Novo Link" (rosa/vermelho)
- Modal "Cadastrar Novo Link": Título do Produto*, URL da Shopee*, Descrição, Preço (placeholder R$ 49,90), Desconto (placeholder 30%), Categoria (placeholder Ex: Cozinha, Decoração...), Imagem do Produto (Upload), botões Cancelar/Cadastrar

## Agendamentos
- Título: "Agendamentos" / "Configure quando cada link será enviado no WhatsApp"
- Cards por dia da semana (Dom, Seg, Ter, Qua, Qui, Sex, Sáb) com contagem de envios
- "Hoje" destacado no dia atual
- Seção "Todos os Agendamentos" com lista: ícone relógio, nome produto, dia/hora (Sex às 23:50), badge "Semanal", botões enviar/excluir
- Botão "+ Novo Agendamento"
- Modal "Criar Agendamento": Link* (select), Dia da Semana (select, ex: Segunda-feira), Hora (select, ex: 09h), Minuto (select, ex: 00min), Mensagem personalizada (opcional), Toggle "Repetir semanalmente" (O envio se repete toda semana no mesmo horário), botões Cancelar/Agendar

## Histórico de Envios
- Título: "Histórico de Envios" / "Acompanhe todos os links enviados e seus status"
- Cards resumo: Enviados (5, verde), Falhas (0, vermelho), Pendentes (0, laranja)
- Seção "Registro de Envios": lista com ícone check verde, nome produto (link externo), data/hora, ícone mensagem, badge "Enviado" (verde)

## Chatbot de Atendimento
- Título: "Chatbot de Atendimento" / "Assistente inteligente para responder dúvidas sobre produtos"
- Chat principal "Assistente Shopee" com badge "Powered by AI"
- Mensagens de usuário (rosa) e bot (amarelo claro)
- Campo "Simule uma pergunta de cliente..."
- Painel lateral direito: "Atendimento Humano" (Nenhum atendimento pendente, conversas que precisam de atenção humana aparecerão aqui)
- Seção "Como funciona": O chatbot usa IA para responder dúvidas sobre produtos cadastrados. Quando não consegue resolver, redireciona automaticamente para atendimento humano.

## Notificações
- Título: "Notificações" / "Acompanhe alertas de envios, falhas e atendimentos"
- Botão "Marcar todas como lidas"
- Badge "3 não lidas"
- Lista: ícone, título "Link enviado com sucesso", descrição 'O link "tapioqueira" foi enviado para o grupo do WhatsApp.', data (21/03, 01:16), ponto azul para não lidas
